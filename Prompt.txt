5. Layers & Responsibilities
Layer	Responsibility
Controller	Thin orchestration layer; calls Service methods; uses Form Requests and Resources
Service	All business logic; coordinates Repositories; handles transactions
Repository	Handles database interactions only; no business logic
Form Requests	Validation and authorization of incoming requests
Policy	Authorization rules for sensitive actions
API Resource	Format and transform JSON responses; use nested/related resources when returning multiple pieces of info
Tests	Unit tests for Services; Feature tests for Controllers and API responses

Nested Resources: When a model has relationships (belongsTo, hasMany), use additional API Resources instead of embedding raw arrays.
