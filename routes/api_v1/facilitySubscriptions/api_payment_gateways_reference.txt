18. Complete API Reference — Gateway Routes
Method	URL	Auth	Description
GET	/api/billing/gateways	✅ Sanctum	List enabled gateways
POST	/api/billing/gateway/{gateway}/initiate	✅ Sanctum	Initiate payment
GET	/api/facilities/{facility}/payments/gateway/{ref}/status	✅ Sanctum	Poll payment status
POST	/api/billing/gateway/{gateway}/webhook	❌ Public	Receive async webhook
GET	/api/billing/gateway/{gateway}/callback	❌ Public	Handle redirect-back
GET	/api/billing/gateway/pesapal/ipn	❌ Public	PesaPal IPN notification

20. Adding a New Gateway in the Future
The architecture is open for extension without touching any existing code:

Copy// 1. Create the driver
// app/Services/Billing/Gateways/Drivers/StripeDriver.php
class StripeDriver implements GatewayDriverInterface { ... }

// 2. Add config entry
// config/billing_gateways.php → 'stripe' => [ ... ]

// 3. Register in AppServiceProvider (no need to touch BillingServiceProvider)
app(GatewayManager::class)->extend('stripe', StripeDriver::class);

// 4. Enable in .env
// STRIPE_ENABLED=true

// That's it — all existing routes, services, and approval flow work automatically.
